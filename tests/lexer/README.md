# Тесты учебного лексера

Положительные файлы проверяют ключевые слова, идентификаторы, числовые и символьные литералы, обычные и интерполированные строки, комментарии и поддерживаемые операторы.

В строках и символах используются только `\n`, `\t`, `\v`, `\\`, `\"` и `\'`. Продолжение строки через обратную косую черту перед физическим переводом строки проверяется отдельно в строковых примерах.

Файлы `lexer_invalid_*` содержат намеренные ошибки. Лексер останавливается на первой ошибке: скрипт ожидает код завершения `1`, сообщение в stderr и указание строки. Если в файле перечислено несколько ошибок, за один запуск проверяется только первая. Директивы и идентификаторы в обратных кавычках не поддерживаются и проверяются как ошибочный ввод.

Это лексические тесты, а не проверка синтаксической или семантической корректности F#. Например, файл ключевых слов содержит отдельные лексемы, а диапазоны типов целых чисел с суффиксами относятся к последующей семантической проверке.

## Запуск

Перед запуском нужно заново сгенерировать `lex.yy.cpp` из текущего `.l` и собрать исполняемый файл лексера. Скрипт тестов этого не делает.

Из корня проекта:

```bat
tests\lexer\run_tests.bat
```

Это самостоятельный BAT-скрипт, которому не нужны PowerShell и дополнительные скрипты. По умолчанию используется `src\x64\Debug\lexer.exe`. Пути по умолчанию определяются относительно расположения скрипта, поэтому его можно запускать из любого рабочего каталога.

Первый необязательный аргумент задаёт исполняемый файл:

```bat
tests\lexer\run_tests.bat "src\x64\Release\lexer.exe"
```

Второй необязательный аргумент задаёт отчёт:

```bat
tests\lexer\run_tests.bat "src\x64\Debug\lexer.exe" "tests\lexer\custom_report.txt"
```

Явно переданные относительные пути отсчитываются от текущего рабочего каталога. Каталог для отчёта должен существовать. По умолчанию отчёт записывается в `tests\lexer\test_report.txt` и перезаписывается при запуске.

Каждый `.fs` и `.fsx` рядом со скриптом запускается отдельным процессом. В отчёте сохраняются stdout, stderr, код завершения и результат проверки. Временные файлы создаются в отдельном каталоге внутри `%TEMP%` и удаляются после выполнения.

Код завершения скрипта: `0` — все тесты пройдены, `1` — есть проваленные тесты, `2` — ошибка запуска или записи файлов либо отсутствие тестов. Для нового тестового файла нужно добавить ожидания в BAT-скрипт; неизвестное имя не считается автоматически успешным тестом.

Скрипт проверяет имена токенов, выбранные однострочные ASCII-значения литералов и диагностические сообщения. Для комментариев и операторов дополнительно проверяется порядок токенов без `NEWLINE`. Для положительных тестов требуется код `0` и пустой stderr.

Unicode и многострочные значения сохраняются в отчёте, но не сравниваются полностью с эталоном. Проверки наличия отдельных сегментов строки не заменяют точное сравнение всей строки. Для побайтовой проверки таких значений можно позднее добавить эталонные файлы и сравнение через `fc /b`.
