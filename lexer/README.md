## 1.1. Ключевые слова

| Лексема | Токен | Назначение |
|---|---|---|

| `as` | `KW_AS` | Имя текущего объекта в конструкторе или имя сопоставленного шаблона. |
| `base` | `KW_BASE` | Обращение к базовому классу. |
| `default` | `KW_DEFAULT` | Реализация виртуального члена по умолчанию. |
| `do` | `KW_DO` | Тело цикла или действие при создании объекта. |
| `downto` | `KW_DOWNTO` | Убывающий счётчик цикла `for`. |
| `elif` | `KW_ELIF` | Дополнительная условная ветвь. |
| `else` | `KW_ELSE` | Альтернативная ветвь. |
| `exception` | `KW_EXCEPTION` | Объявление исключения. |
| `false` | `BOOL_FALSE` | Логическое значение ложь. |
| `finally` | `KW_FINALLY` | Завершающий блок обработки исключений. |

| `in` | `KW_IN` | Перебираемая коллекция в `for ... in`. |

| `internal` | `KW_INTERNAL` | Доступ в пределах сборки. |

| `match` | `KW_MATCH` | Сопоставление с образцами. |
| `member` | `KW_MEMBER` | Объявление метода или свойства. |

| `override` | `KW_OVERRIDE` | Переопределение члена. |
| `private` | `KW_PRIVATE` | Закрытый доступ. |

| `rec` | `KW_REC` | Рекурсивная функция `let rec`. |
| `static` | `KW_STATIC` | Статический метод или свойство. |
| `then` | `KW_THEN` | Ветвь условия или действие после дополнительного конструктора. |
| `to` | `KW_TO` | Возрастающий счётчик цикла `for`. |
| `true` | `BOOL_TRUE` | Логическое значение истина. |
| `try` | `KW_TRY` | Начало обработки исключений. |
| `type` | `KW_TYPE` | Объявление класса, интерфейса или перечисления. |

| `when` | `KW_WHEN` | Условие ветви сопоставления. |
| `while` | `KW_WHILE` | Цикл с предусловием. |
| `with` | `KW_WITH` | Ветви `match`/`try` и описание доступа к свойству. |
| `yield` | `KW_YIELD` | Выдача элемента последовательности `seq { ... }`. |
| `and` | `KW_AND` | Связывает взаимно рекурсивные определения. |

| `inline` | `KW_INLINE` | Объявление встраиваемой функции или члена. |
| `lazy` | `KW_LAZY` | Создание отложенного вычисления. |
| `module` | `KW_MODULE` | Объявление модуля. |
| `namespace` | `KW_NAMESPACE` | Объявление пространства имён. |
| `null` | `KW_NULL` | Нулевая ссылка, в том числе результат `ReadLine()` при окончании ввода. |
| `open` | `KW_OPEN` | Доступ к содержимому модуля или пространства имён без полной квалификации. |
| `or` | `KW_OR` | Слово совместимости с ML; не заменяет логический оператор ИЛИ. |
| `return` | `KW_RETURN` | Возврат значения внутри computation expression. |
| `return!` | `KW_RETURN_BANG` | Возврат результата вложенного вычисления. |
| `select` | `KW_SELECT` | Выбор результата в query expression; в данном файле распознаётся без учёта контекста. |
| `struct` | `KW_STRUCT` | Объявление структуры или структурной формы типа. |
| `upcast` | `KW_UPCAST` | Приведение к базовому типу. |
| `val` | `KW_VAL` | Объявление значения, сигнатуры или явного поля. |
| `void` | `KW_VOID` | Тип `System.Void`, преимущественно для внешних объявлений; обычные процедуры F# возвращают `unit`. |
| `yield!` | `KW_YIELD_BANG` | Выдача всех элементов вложенной коллекции или последовательности. |

### Имена, не являющиеся ключевыми словами

| Имена | Токен | Использование |
|---|---|---|
| `int`, `char`, `string`, `bool`, `unit`, `float`, `float32`, `decimal` | `IDENTIFIER` | Имена типов и функций преобразования. |
| `printf`, `printfn` | `IDENTIFIER` | Форматированный вывод. |
| `System`, `Console`, `Write`, `WriteLine`, `ReadLine` | `IDENTIFIER` | Части имён консольных методов .NET. |
| `not` | `IDENTIFIER` | Функция логического отрицания. |
| `seq` | `IDENTIFIER` | Построитель последовательности. |
| `get`, `set` | `IDENTIFIER` | Контекстные имена методов доступа к свойству. |
| `IDisposable`, `Dispose` | `IDENTIFIER` | Интерфейс и метод освобождения ресурсов. |
| `raise`, `failwith` | `IDENTIFIER` | Возбуждение исключений. |

## 1.2. Идентификаторы

| Элемент | Правило |
|---|---|
| Первый символ | Unicode-буква (категории `Lu`, `Ll`, `Lt`, `Lm`, `Lo`, `Nl`) или `_`. |
| Последующие символы | Буквы, цифры `0-9`, `_`, апостроф `'`, символы категорий `Pc`, `Mn`, `Mc`, `Cf`. |
| Регистр | Значим: `value` и `Value` являются разными именами. |
| Ключевое слово | Полное совпадение с таблицей из п. 1.1 возвращает соответствующий ключевой токен. |
| Одиночный `_` | Отдельный токен `WILDCARD` для шаблона или неиспользуемого параметра. |
| Квалифицированное имя | `System.Console.ReadLine` разбивается на идентификаторы и точки, а не образует одну лексему. |

## 1.3. Константы и литералы

### Целые числа

| Вид | Форма | Примеры |
|---|---|---|
| Десятичный | Цифры `0-9` | `0`, `42`, `123_456` |
| Шестнадцатеричный | `0x`/`0X` и цифры `0-9`, `a-f`, `A-F` | `0xFF`, `0XDEAD_BEEF` |
| Восьмеричный | `0o`/`0O` и цифры `0-7` | `0o77`, `0O123_456` |
| Двоичный | `0b`/`0B` и цифры `0-1` | `0b1010`, `0B1111_0000` |

| Суффикс | Тип в F# | Пример |
|---|---|---|
| Нет или `l` | `int`/`int32` | `42`, `42l` |
| `y` | `sbyte` | `42y` |
| `uy` | `byte` | `42uy` |
| `s` | `int16` | `42s` |
| `us` | `uint16` | `42us` |
| `u`, `ul` | `uint32` | `42u`, `42ul` |
| `n` | `nativeint` | `42n` |
| `un` | `unativeint` | `42un` |
| `L` | `int64` | `42L` |
| `UL`, `uL` | `uint64` | `42UL`, `42uL` |
| `I` | `bigint` | `12345678901234567890I` |

### Числа с плавающей точкой

| Вид | Примеры | Токен |
|---|---|---|
| `float` | `3.14`, `10.`, `0.5`, `3e-4`, `1.0E+10` | `FLOAT64_LITERAL` |
| `float32`, суффикс `f`/`F` | `3.14f`, `3F`, `2.3e10F` | `FLOAT32_LITERAL` |
| `decimal`, суффикс `m`/`M` | `3.14M`, `100m` | `DECIMAL_LITERAL` |

### Логические и единичное значения

| Форма | Токенизация | Значение |
|---|---|---|
| `true`, `false` | `BOOL_TRUE`, `BOOL_FALSE` | Значения `bool`. |
| `()` | `LPAREN`, `RPAREN` | Значение `unit`, в том числе результат цикла или процедуры. |

### Символы

| Вид | Форма и примеры | Токен и правило |
|---|---|---|
| Символьный литерал | `'a'`, `'Ж'`, `'\n'`, `'\t'`, `'\v'`, `'\\'`, `'\''` | `CHAR_LITERAL`: один символ или escape-последовательность между одинарными кавычками; значение представимо одним `System.Char`. |

### Escape-последовательности

| Последовательность | Значение |
|---|---|
| `\n` | Перевод строки. |
| `\t` | Горизонтальная табуляция. |
| `\v` | Вертикальная табуляция. |
| `\\` | Обратная косая черта. |
| `\"` | Двойная кавычка. |
| `\'` | Одинарная кавычка. |
| `\` перед физическим переводом строки | Продолжение обычной строки без добавления перевода и начальных пробелов следующей строки. |

### Строки

| Вид | Форма и пример | Токен и правило |
|---|---|---|
| Обычная | `"Hello\nWorld"` | `STRING_LITERAL`: обработка escape; физические переводы строк допустимы. |
| Интерполированная обычная | `$"Value = {x}"` | Текстовые сегменты с escape и выражения в `{...}`. |

## 1.4. Операции и синтаксические знаки

### Операции

| Лексема | Токен | Назначение |
|---|---|---|
| `+` | `OP_PLUS` | Сложение или унарный плюс. |
| `-` | `OP_MINUS` | Вычитание или унарный минус. |
| `*` | `OP_MUL` | Умножение; также разделение типов параметров метода в сигнатуре. |
| `/` | `OP_DIV` | Деление. |
| `%` | `OP_MOD` | Остаток от деления, прямо указанный в карточке. |
| `=` | `OP_EQUAL_OR_EQUALS_SIGN` | Сравнение на равенство или разделитель объявления. |
| `<>` | `OP_NOT_EQUAL` | Неравенство. |
| `<`, `<=` | `OP_LT`, `OP_LE` | Меньше, меньше либо равно. |
| `>`, `>=` | `OP_GT`, `OP_GE` | Больше, больше либо равно. |
| `<-` | `OP_ASSIGN` | Обновление изменяемой переменной, свойства или элемента массива. |
| `&&` | `OP_BOOL_AND` | Логическое И с сокращённым вычислением. |
| <code>&#124;&#124;</code> | `OP_BOOL_OR` | Логическое ИЛИ с сокращённым вычислением. |
| `not` | `IDENTIFIER` | Функция логического отрицания. |
| `::` | `OP_CONS` | Голова и хвост списка в выражении или шаблоне. |

### Синтаксические знаки

| Лексема | Токен | Назначение |
|---|---|---|
| `->` | `ARROW` | Тело анонимной функции, результат ветви или тип результата функции. |
| `.` | `DOT` | Квалифицированное имя, доступ к члену, начало индексации `array.[i]`. |
| `..` | `RANGE` | Диапазон в цикле или коллекции. |
| `:` | `COLON` | Аннотация типа. |
| `(`, `)` | `LPAREN`, `RPAREN` | Группировка, параметры методов/конструкторов, значение `unit`. |
| `[`, `]` | `LBRACKET`, `RBRACKET` | Список или индекс элемента массива. |
| <code>[&#124;</code>, <code>&#124;]</code> | `ARRAY_START`, `ARRAY_END` | Ограничители массива. |
| `{`, `}` | `LBRACE`, `RBRACE` | Последовательность `seq { ... }`; внутри интерполированной строки обрабатываются её состоянием. |
| `,` | `COMMA` | Разделитель параметров/аргументов методов и конструкторов, компонентов шаблона. |
| `;` | `SEMICOLON` | Разделитель элементов коллекции или последовательных выражений. |
| <code>&#124;</code> | `BAR` | Ветвь сопоставления, вариант перечисления или альтернативный шаблон. |
| `_` | `WILDCARD` | Любое значение в шаблоне или неиспользуемый параметр. |

## 1.5. Комментарии

| Вид | Начало | Конец | Обработка |
|---|---|---|---|
| Однострочный | `//` | Перевод строки или EOF | Пропустить содержимое, сохранить позицию и значимый перевод строки. |
| Блочный | `(*` | Соответствующий `*)` | Пропустить содержимое, учитывать вложенность и строки. |
