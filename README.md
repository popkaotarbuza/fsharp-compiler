# Учебный компилятор F#

## Объём реализации

| Требование карточки | Необходимые конструкции |
|---|---|
| Локальные переменные `int`, `char`, `string` и выражения | `let`, `mutable`, `<-`, арифметика и сравнения |
| Одномерные массивы и доступ к элементу | <code>[&#124; ... &#124;]</code>, `array.[i]`; указанные в карточке списки `[ ... ]` и последовательности `seq { ... }` |
| Целые, символьные и строковые литералы | Основания `10`, `16`, `8`, `2`, разделители `_`, суффиксы, Unicode, escape-последовательности и виды строк из карточки |
| Развилки | `if ... then ... elif ... else`, `match ... with`, `when` |
| Циклы | `for ... in`, `for ... to/downto`, `while ... do`, диапазоны `..` |
| Функции | `let`, каррированные параметры, `fun ... ->`, `let rec`, `function` |
| Консольный ввод и вывод | `printf`, `printfn`, `System.Console.Write`, `WriteLine`, `ReadLine` |
| Классы, свойства, методы и наследование | `type`, `member`, `inherit`, `interface`, `abstract`, `default`, `override` |
| Числа с плавающей точкой | `float`, `float32`, `decimal`, литералы и операции |
| Логические операции | `&&`, <code>&#124;&#124;</code>, `not`, значения `bool` |
| Контроль доступа | `public`, `private`, `internal`, обращение через `base` |
| Конструкторы и освобождение ресурсов | Первичный конструктор, `new`, `IDisposable`, `use`, `use!` |
| Перегрузка по параметрам | Объявления методов и конструкторов с аннотациями типов; отдельной лексемы перегрузки нет |
| Перечисления | `type Color =` с вариантами вида `Red = 0`, разделёнными вертикальной чертой |
| Исключения | `try ... with`, `try ... finally`, `exception`, `raise`, `failwith` |

Распознавание лексем не означает реализацию всех типов и библиотек F#. Например, карточка требует один основной целочисленный тип `int`, но отдельно упоминает суффиксы целых литералов: лексер сохраняет суффикс, а проверка типа выполняется на семантической стадии.

Таблица лексем и правила их распознавания приведены в [README лексера](lexer/README.md).
